## Project Summary

Fixora is a vehicle repair and mechanic service integration system designed to connect customers with nearby mechanic shops. The system allows customers to request vehicle repair services, provide information about their vehicle problems, select a mechanic shop, and monitor the status of their booking. Mechanic shops can manage service requests, update their shop information and location, and respond to customer bookings. An administrator can monitor users, mechanic shops, bookings, and other system activities through an administrative dashboard.

The system aims to provide a more organized and convenient way for customers and mechanic shops to manage vehicle repair service transactions.

## Collaboration Workflow

1. Pull the latest changes from the `main` branch.
2. Create a feature or documentation branch.
3. Make the required changes.
4. Add and commit the changes.
5. Push the branch to GitHub.
6. Create a Pull Request.
7. Request a review from a teammate.
8. Resolve requested changes or conflicts.
9. Merge the Pull Request into `main`.
